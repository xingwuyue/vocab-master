# VocabMaster - 英语词汇学习网站

## 项目概述
一个分阶段、可复习的英语词汇学习网站

## 核心功能

### 1. 阶段系统（5个阶段）
- 阶段1: 高频1000词（最核心基础）
- 阶段2: +2000词 = 3000词（日常交流）
- 阶段3: +2000词 = 5000词（进阶提升）
- 阶段4: +5000词 = 10000词（中高级）
- 阶段5: +20000词 = 30000词（精通级）

### 2. 学习模式
- **新词学习**：展示单词、音标、释义、例句
- **复习模式**：基于艾宾浩斯遗忘曲线的间隔重复
- **测试模式**：看英文选中文 / 看中文选英文 / 听写

### 3. 进度追踪
- 每个阶段学习进度
- 已掌握 / 学习中 / 待学习 状态
- 学习统计数据

### 4. 复习系统
- 使用 localStorage 保存学习记录
- 智能复习提醒（根据掌握程度）
- 错题本功能

## 技术栈
- HTML5 + CSS3 + Vanilla JS
- LocalStorage 数据持久化
- 响应式设计（移动端友好）
- 离线可用（PWA）

## 设计风格
- 现代简约风
- 渐变色主题
- 流畅动画
- 深色/浅色模式
